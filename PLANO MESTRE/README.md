# Plano Mestre de Comunicação — Pepê Collaço 2026

Documento-guia central da comunicação, organização e produção da campanha.
Arquivo principal: **`Plano_Mestre_Comunicacao_Pepe_Collaco.html`**

**Edição 2.0** — tema escuro "arena digital" na paleta oficial (azul-marinho /

28 capítulos. Editável direto no navegador.

## Editar o documento (mantendo o layout)

No topo da tela há dois botões:
- **✏️ Editar** — liga o modo de edição: clique em qualquer texto e digite
  (preencher responsáveis, prazos, metas, etc.). Todo o layout é preservado.
- **💾 Baixar HTML** — salva sua versão editada como um novo arquivo `.html`
  (autossuficiente, abre e edita de novo a qualquer momento).

## Inserir imagens (dashboards, artes, fotos)

**Jeito fácil (recomendado):** abra o `.html` no Chrome. Em cada caixa tracejada
`[ ESPAÇO RESERVADO ]` aparece o botão **"＋ Inserir imagem"**. Clique, escolha
a foto no computador e ela entra no lugar. A imagem é:
- **redimensionada** automaticamente (até 1600 px) para o arquivo não ficar pesado;
- **embutida dentro do HTML** (vira parte do arquivo) — não quebra se você mover
  ou enviar o arquivo, e é preservada ao clicar em **"💾 Baixar HTML"**.

Depois de inserida, a imagem mostra uma barra de controles:
- **P / M / G / Total** — ajustam a largura da imagem na página (45% / 70% / 90% / 100%).
- **Trocar** — escolhe outra foto no lugar.
- **Remover** — volta o espaço ao estado original (o texto do documento não é afetado).

Para escrever a legenda, ative **"✏️ Editar"** e clique sobre o texto da legenda.

## Salvar e recuperar o que você editou

- As edições (texto, imagens, tamanhos) são **salvas automaticamente neste
  navegador**. Ao reabrir o arquivo aparece uma barra verde **"Há uma edição
  salva… [Restaurar] [Descartar]"** — clique em **Restaurar** para voltar de onde
  parou.
- Para guardar um arquivo definitivo (enviar, imprimir, fazer backup), use
  **"💾 Baixar HTML"** — gera um `.html` autossuficiente com tudo dentro.
- Se você inserir muitas imagens grandes, o auto-salvamento do navegador pode
  pausar (limite do navegador) — nesse caso use **"💾 Baixar HTML"**.
- O salvamento do navegador é por navegador/computador. O arquivo do
  **"Baixar HTML"** é o que você leva para qualquer lugar.

**Jeito manual (editando o código):** substitua um bloco placeholder por:
```html
<figure class="fig">
  <img src="imagens/minha-foto.jpg" alt="descrição">
  <figcaption>Legenda da imagem.</figcaption>
</figure>
```
Coloque o arquivo numa subpasta `imagens/` dentro de `PLANO MESTRE/` e use o
caminho relativo (`imagens/...`). A classe `.fig` já aplica borda, cantos
arredondados e legenda no estilo do documento.

## Como gerar o PDF profissional

1. Abra o `.html` no **Google Chrome** (duplo clique).
2. `Ctrl/Cmd + P` → **Imprimir**.
3. Destino: **Salvar como PDF**.
4. Tamanho do papel: **A4** · Margens: **Nenhuma**.
5. Marque **"Gráficos de plano de fundo"** (Background graphics).
6. Salvar.

O documento foi desenhado com quebras de página A4 — sai limpo, com capa, divisórias de parte e capítulos começando em página nova.
